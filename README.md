# erl_lib_dist
------------
A library for SMPP Adapter written in Erlang language -- with the emphasize on re-usability and high-performance.

## Library and Documentation Migration
The library (code releases) were previously downloadable from company website. However, in order to make integration
and deployment easier from client perspective, both library and documentation have since been moved to this GitHub page.
